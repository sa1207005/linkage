# LinkAge

長者社會參與與陪伴追蹤平台 Prototype。

讓每一次接觸，都累積成對一個人的理解。

所有個案、人物與紀錄皆為虛構示範資料；AI 結果為前端示範，沒有後端、真實帳號驗證或 AI API。示範操作資料僅保存在目前分頁的 sessionStorage，不會跨裝置同步。

## GitHub Pages

在儲存庫 Settings → Pages，選擇 Deploy from a branch、main、/(root)，儲存。

網站入口為 index.html，其餘檔案使用相對路徑，支援 /linkage/ 專案網址。

## 更新

從 LinkAge/site/dist 複製最新的 index.html、style.css、app.js、logo.svg 至儲存庫根目錄，提交至 main 後由 GitHub Pages 發布。
